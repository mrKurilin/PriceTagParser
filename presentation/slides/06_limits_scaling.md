# Ограничения и масштабирование
Как развивать решение после MVP

- **Ограничения текущего подхода**:
  - качество зависит от освещения, резкости видео и угла съемки
  - OCR может ошибаться на бликах, мелких шрифтах и нестандартных макетах ценников
  - без deduplication один и тот же ценник может попасть в CSV несколько раз
  - локальное файловое хранилище подходит для демо, но не для высокой нагрузки
- **Как повышать качество**:
  - добавить трекинг ценников между кадрами и агрегацию OCR-результатов
  - хранить crop-изображения спорных ценников для ручной валидации
  - считать confidence и выделять записи, требующие проверки оператором
- **Как масштабировать**:
  - вынести обработку в очередь задач и отдельные воркеры
  - хранить видео и CSV в object storage
  - добавить базу метаданных, историю запусков и статусы задач
  - подключить мониторинг качества распознавания и времени обработки
