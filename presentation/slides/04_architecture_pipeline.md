# Архитектура и пайплайн
От загрузки видео до скачивания CSV

- **Web UI**: Compose Multiplatform/Wasm — список файлов, загрузка видео, статусы `Загрузка`, `Обработка`, `Скачать`
- **Backend API**: Ktor — `POST /api/upload`, `GET /api/files`, `GET /api/files/{name}/download`
- **Хранилище**: локальная папка `server/files`, рядом с видео появляется одноименный CSV-файл
- **Скрипт обработки**: отдельный процесс, который забирает загруженное видео, прогоняет CV/OCR-пайплайн и сохраняет CSV
- **Логика пайплайна**:
  - извлечь кадры из видео с заданным шагом
  - найти области ценников и товаров на кадрах
  - распознать текст, цену и дополнительные признаки
  - объединить повторы одного ценника между кадрами
  - записать нормализованный результат в CSV
- **Плюс архитектуры**: UI и API уже отделены от ML-скрипта, поэтому модель можно менять без переписывания пользовательского сценария
