# Демонстрация интерфейса и CSV
Пользовательский сценарий за 3 шага

- **Шаг 1**: пользователь открывает PriceTagParser и видит список ранее загруженных файлов
- **Шаг 2**: пользователь нажимает `+`, выбирает видео полки и видит прогресс загрузки
- **Шаг 3**: после обработки рядом с файлом появляется кнопка `Скачать`, которая возвращает CSV
- **Пример выходного датасета**:
  - `source_file` — имя исходного видео
  - `frame_time` — время кадра или интервал, где найден ценник
  - `product_name` — распознанное название товара
  - `price` — распознанная цена
  - `currency` — валюта
  - `confidence` — уверенность распознавания
  - `bbox` — координаты области ценника для ручной проверки
- **Демо-статус**: загрузка и скачивание CSV уже поддержаны интерфейсом и API; генерация CSV будет добавлена скриптом обработки
